# Example: Using erwartung for the german dataset "Marktstammdatenregister"

The Marktstammdatenregister (short: mastr) is a dataset of electricity producers in Germany, including wind turines, pv systems, ...


1. Make sure that you have linkml-map installed: `pip install linkml-map`
1. Make the `main.sh` script executable and run it to map the `CIM` schema from `erwartung` to the data schema of the Marktstammdatenregister.
